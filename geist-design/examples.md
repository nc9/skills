# Examples

Reference sites for the Geist aesthetic, with what each does distinctively well. When in doubt about a specific decision, look at what these brands do — they're the canonical reference.

Inspect with browser dev tools to extract specific values. The pattern is more reliable than my recall.

---

## Tier 1 — The defining references

### Vercel — [vercel.com](https://vercel.com)

The reference brand. Everything in this aesthetic is benchmarked against Vercel.

**What they do best**:
- Pure black/white with surgical use of color
- Geist Sans + Geist Mono (their own typeface, free)
- Beam/spotlight gradients in heroes
- Aurora animated borders on premium CTAs
- Sharp corners or near-sharp (0–4px radius) on marketing pages
- Mono used everywhere — version numbers, paths, navigation
- Hairline-bordered cards as the default container
- Code as hero imagery
- 10-step P3 color system documented at [vercel.com/geist/colors](https://vercel.com/geist/colors)

**Inspect**: [vercel.com](https://vercel.com), [vercel.com/changelog](https://vercel.com/changelog), [vercel.com/docs](https://vercel.com/docs), [nextjs.org](https://nextjs.org)

**Studyable**: their Geist design system is publicly documented at [vercel.com/geist](https://vercel.com/geist) with Figma files, color tokens, and component reference.

### Linear — [linear.app](https://linear.app)

The other defining reference. Slightly warmer than Vercel, more product-screenshot-driven.

**What they do best**:
- Inter + Inter Display + Berkeley Mono — premium type stack
- Dark-first marketing with `#0a0a0a`-style backgrounds
- Subtle desaturated blue brand color (not vivid)
- Cinematic product screenshots as hero
- 8px spacing scale, religiously applied
- "Orbiter" internal design system (not public, but visible in product)
- Recent (2026) design refresh: warmer grays, reduced icon usage, softer borders

**Inspect**: [linear.app](https://linear.app), [linear.app/changelog](https://linear.app/changelog), [linear.app/now](https://linear.app/now) (their blog)

**Notable post**: [Behind the latest design refresh](https://linear.app/now/behind-the-latest-design-refresh) — they share their thinking on warm vs cool grays.

### Stripe — [stripe.com](https://stripe.com)

The originator of much of this aesthetic. Slightly more polished/corporate than Vercel/Linear.

**What they do best**:
- Söhne typeface (premium, Klim Type Foundry)
- Indigo brand color (#635bff) as accent
- Famous "rainbow gradient" hero (the conic-gradient-with-globe)
- Animated 3D globe / abstract spheres as hero imagery
- Heavy use of gradient washes and atmospheric depth
- Camphor (their custom typeface) historically; now Söhne
- Tight, premium type pairing throughout

**Inspect**: [stripe.com](https://stripe.com), [stripe.com/sessions](https://stripe.com/sessions), [stripe.com/atlas](https://stripe.com/atlas), [stripe.press](https://stripe.press) (a different aesthetic, editorial)

**Caveat**: Stripe is more "polished agency" than "scrappy dev tool" — their work is closer to high-end editorial than to the Vercel/Linear/Resend cluster. Useful as a reference for marketing-page polish; less useful for product UI.

## Tier 2 — Strong references with distinct flavor

### Resend — [resend.com](https://resend.com)

Email API. Minimal dark theme, monospace-heavy.

**What they do best**:
- Almost-pure black backgrounds
- Heavy mono usage as UI text
- Restrained orange accent
- Minimalist composition — lots of negative space, few elements per section
- Code blocks as hero/feature imagery

**Notable**: extremely consistent voice. Easy to study because they don't deviate.

### Raycast — [raycast.com](https://raycast.com)

Productivity launcher. More vivid/colorful than the others while staying in family.

**What they do best**:
- Sleek dark chrome as marketing background
- Vibrant gradient accents (red/pink primary)
- Animated gradient hero section
- Strong product screenshot integration
- Polished hover states and micro-interactions

**Notable**: pushes the aesthetic toward "playful but still serious." Useful when you want more energy without leaving the family.

### Cursor — [cursor.com](https://cursor.com)

AI-first code editor. Sleek dark, gradient accents.

**What they do best**:
- Pure black hero with subtle gradient atmosphere
- Heavy use of code-as-imagery
- Tight typography, weight restraint
- Minimal nav with mono labels
- Very confident use of empty space

### Supabase — [supabase.com](https://supabase.com)

Open-source Firebase alternative. Dark emerald, code-first.

**What they do best**:
- Dark `#171717` backgrounds (warmer than pure black)
- Emerald green (#3ecf8e) as restrained accent — never as background
- Circular typeface throughout (premium)
- **Hero line-height 1.0** — zero-leading display text is their typographic signature
- Weight restraint: only 400 and 500 across the entire site
- Source Code Pro mono uppercase labels for "developer-context" markers
- Borders, not shadows, for elevation (#242424 → #2e2e2e → #393939 hierarchy)
- Pill-shaped (9999px radius) primary CTA buttons

**Inspect**: [design.hagicode.com/designs/supabase](https://design.hagicode.com/designs/supabase) has a thorough breakdown.

### PlanetScale — [planetscale.com](https://planetscale.com)

Database. Black/white precision, heavy on the engineering aesthetic.

**What they do best**:
- Recent rebrand leaned harder into pure black + sharp edges
- Mono everywhere — even for body labels
- Confident use of bare white space
- Code/terminal as hero
- Very Vercel-adjacent in execution

### Modal — [modal.com](https://modal.com)

Cloud functions/AI compute platform. Cyan-accented dark.

**What they do best**:
- Dark with cyan/teal accent
- Heavy code-snippet usage in hero
- Compact, dense feature grids with hairline borders
- Restrained, technical voice
- Strong example of "developer-tool docs" aesthetic applied to marketing

### Inngest — [inngest.com](https://inngest.com)

Background jobs. Similar tier — restrained, dark, technical.

### Liveblocks — [liveblocks.io](https://liveblocks.io)

Realtime collaboration infra.

**What they do best**:
- Light-mode-first marketing (rare and well-executed)
- Subtle gradient hero
- Hairline-bordered cards everywhere
- Strong type hierarchy
- Pleasant, restrained color (subtle blue)

### Clerk — [clerk.com](https://clerk.com)

Auth platform.

**What they do best**:
- Polished light + dark mode
- Strong hero composition with product screenshot at angle
- Gradient atmospheric backgrounds
- Premium type pairing

### Neon — [neon.tech](https://neon.tech)

Postgres. Dark, technical, with their distinctive light-streak gradients.

### Trigger.dev — [trigger.dev](https://trigger.dev)

Background jobs. Dark with restrained color.

Headless CMS. Red accent, more editorial than the others, but uses many of the same primitives.

## Component-level references

For pure component vocabulary, study:

- **shadcn/ui** ([ui.shadcn.com](https://ui.shadcn.com)) — the de facto component library for this aesthetic. Defaults are correct out of the box.
- **Geist UI** ([geist-ui.dev](https://geist-ui.dev)) — community React port of Vercel's design system. Slightly stylized but on-brand.
- **Radix UI** ([radix-ui.com](https://radix-ui.com)) — the primitives Linear and many others use under the hood. Unstyled but the right shape.
- **Tremor** ([tremor.so](https://tremor.so)) — dashboard component kit in this aesthetic. Useful for data-heavy UIs.
- **HeroUI** ([heroui.com](https://heroui.com)) — Linear-inspired component kit, opinionated but in family.

## What to look at when studying these sites

When inspecting an exemplar in dev tools, focus on:

1. **Computed font-family** on body and headings.
2. **font-size and letter-spacing** on the largest headline.
3. **CSS variables** in :root and dark-mode toggle (most use design tokens).
4. **Border colors and widths** on cards (almost always 1px, low-contrast).
5. **Box-shadow** on cards (usually `none` — this is the defining test).
6. **Transition durations** on hover states (150–250ms).
7. **Background-image** on hero sections (often radial gradients).
8. **Spacing between sections** (often 96–160px padding-y).

If you're doing this regularly, install a design-token extractor extension (e.g. CSS Peeper, FontOfWeb, Design System Extractor for Chrome) — the manual approach gets old fast.

---

## Use these references thoughtfully

These brands work because they're consistent within themselves, not because they're identical to each other. Don't try to merge Linear's warmth with Vercel's pure-black or Supabase's emerald with Stripe's indigo. Pick the closest reference to your project and stay coherent with that one's choices.

The aesthetic is a family, not a template.
